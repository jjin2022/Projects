## 📈 Engineering Approach

I enjoy working across the entire engineering development process:

1. **Design** — Define the problem and develop a system architecture.
2. **Build** — Integrate mechanical components, electronics, and software.
3. **Test** — Validate performance through simulation and physical experiments.
4. **Improve** — Analyze results, troubleshoot limitations, and refine the design.
5. **Document** — Record methods, results, and lessons learned for reproducibility.
